# Config Values

Certain aspects of the frontend can be configured using the `frontend/config.json` file.

Here are the following configurable values and what they do.

## showPractice
This settings toggles if the practice area is shown on the nav bar.

## showLoginSplash
This setting toggles if the login splash screen should be shown.

## welcomeSplashPage
Configurable settings for the login splash page.

### siteName
This is the site name for your event in a readable format. Ex. J. Smith's CTF

## link
This is the link to your site. Ex example.com
