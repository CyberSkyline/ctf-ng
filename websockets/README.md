# WebSocket Testing Guide

## 1. Start the Support Test Server

Run the following command:

```bash
npm run test-support
````

In your browser, navigate to:

```
http://localhost/
```

Set up an administrative user in CTFD


## 2. Open the Test Harness

In your browser, navigate to:

```
http://localhost/test-harness
```

## 3. Perform Test Actions

Once the test harness is open:

* **Connect to WebSockets**

* **Join a Room**

* **Create an Event**

* **Create a Team**

* **Create a Ticket**
  
* **Close the Ticket**

Repeat actions as needed to test different socket events and flows.
